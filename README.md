# Kero-s-Batocera-Flash-120
A free, preconfigured Batocera gaming image featuring a curated library of classics, including Mario Kart Wii, Super Smash Bros. Melee, Minecraft, Crash Bandicoot, DOOM, and more. Configured for a 120gb hard drive, but comes with 70gb of free space for you to add more games if you wish to.
